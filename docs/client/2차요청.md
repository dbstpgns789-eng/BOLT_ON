# 2차 요청 메시지 초안 (2026-11-10)

> **변경(2026-11-10 오후)**: 법인 설립 중이라 메시지 A의 1·2·3번(사업자등록증, 면허증, 영문 상호)은 법인이 나오는 대로 받는다. 영문 상호는 디스코드로 이미 요청했다. 나머지 항목은 그대로 보낸다. 시공사례가 아버님 사업체 시절 공사인지도 함께 확인한다.

카톡이나 디스코드에 그대로 붙여 넣는 일반 텍스트이다. 메시지 A(자료 요청)를 먼저 보내고, 메시지 B(진행 방식 확인)는 따로 보낸다(그릴링 Q5 결정). 근거: `docs/PLAN.md` 4절.

## 메시지 A: 추가 자료 요청

```
준혁아, 요청서 잘 받았어! 덕분에 구성은 거의 다 잡았어.
홈페이지 만들면서 꼭 필요한 것만 추렸으니까, 아래 순서대로 보내 주면 돼.

━━━━━━━━━━━━━━━
[꼭 필요한 것] 이게 있어야 오픈할 수 있어
━━━━━━━━━━━━━━━
1. 사업자등록증 사진
   → 사이트 맨 아래 회사 정보(사업자번호, 정식 상호, 주소)에 들어가.

2. 전기공사업 등록증(면허증) 사진
   → 요청서에 '면허 없음'으로 체크돼 있었는데, 전기공사는 등록증이 있어야 할 수 있는 거라 혹시 잘못 체크한 건가 해서!
   → 면허번호가 사이트에 있으면 신뢰도가 확 올라가.

3. 영문 회사 이름 확인
   → 요청서에는 "Volt on E&C", 로고에는 "BOLT-ON E&C"로 돼 있어. 어느 쪽이 맞아?
   → 이걸로 홈페이지 주소(도메인)를 정해. 지금 쓸 수 있는 주소 후보야:
      BOLT-ON이면: bolton-enc.com / bolt-on.co.kr
      Volt on이면: voltonenc.com / voltonenc.co.kr
      (boltonenc.com은 이미 다른 사람이 쓰고 있어)

4. 카카오톡 채널 주소
   → 홈페이지 '카톡 상담' 버튼에 연결할 거야. 채널이 아직 없으면 말해 줘, 만드는 방법 알려 줄게.

5. 시공사례 사진 3곳 (카톡으로 보낼 때 꼭 '원본' 선택!)
   → 서대문형무소 / 제이알 배터리 / (주)조양
   → 김해 미술관이랑 하나임푸드는 받았어.

6. 시공사례에 회사 이름을 그대로 써도 될까?
   → 요청서에 '거래처 소개 안 함'이라고 돼 있어서 확인하는 거야.
   → 지금은 김해 미술관, 서대문형무소 같은 공공시설만 실명으로 쓰고,
     민간 회사는 "청주 식품공장 변전실 공사"처럼 이름 빼고 쓰려고 해.
   → 다 실명으로 써도 되면 그렇게 할게.

━━━━━━━━━━━━━━━
[가능하면] 있으면 훨씬 좋아지는 것
━━━━━━━━━━━━━━━
7. 시공사례 정보 (아는 것만 채워 줘, 모르는 칸은 비워도 돼)
   아래를 복사해서 현장마다 채워 주면 돼:

   현장:
   지역(시/구/동까지):
   건물 종류(공장, 상가, 미술관 등):
   공사 내용(예: 변압기 교체, 증설):
   용량(예: 500kVA, 50kW→100kW):
   공사 끝난 달(예: 2026년 3월):
   공사 기간(예: 2주):
   공사 전 사진 / 공사 후 사진이 어느 건지:

   (김해 미술관은 요청서에 2025년인데 개관이 2026년 4월이더라. 착공이 2025년인 거 맞지?)

8. 사업분야를 이렇게 5개로 정리했는데 괜찮아?
   ① 고압 수변전설비 공사
   ② 전기 증설·승압 공사
   ③ 변압기 교체 공사
   ④ 내선·리모델링 전기공사
   ⑤ 신·증축 전기공사
   → 소개글에 있던 승압이랑 리모델링도 넣었어. 빠지거나 안 하는 게 있으면 말해 줘.
   → 설명 글은 내가 새로 쓰고, 내용이 맞는지만 나중에 봐 주면 돼.

9. 신뢰를 높이는 정보 (있는 것만)
   → 대표 경력 몇 년인지, 가진 자격증(전기기사 등), 보유 장비

10. 홈페이지에 문의 글 남기는 칸이 필요해?
   → 요청서에서 '전화 + 카톡'만 골라서, 지금은 그 둘로만 받으려고 해.
   → 문의 칸을 만들면 개인정보처리방침도 같이 올려야 해서, 필요 없으면 안 만드는 게 깔끔해.

11. 사진은 없어도 되는 최근 공사 이력
   → 한 줄씩만 적어 주면 사례 페이지 아래에 실적 표로 넣을게 (회사 이름은 빼고).
   예: 남양주 / 상가 전기 증설 / 50kW→100kW / 2026

   앞으로도 공사 끝날 때마다 사진이랑 이 한 줄 보내 주면 내가 계속 올릴게!

━━━━━━━━━━━━━━━
1~4번만 먼저 와도 바로 첫 화면 시안 작업 들어갈 수 있어.
사진 많으면 이메일이나 구글 드라이브도 괜찮아.
```

## 메시지 B: 진행 방식 확인 (메시지 A 다음에 따로 보냄)

```
그리고 진행 방식 한 번 정리해서 보내 둘게. 괜찮으면 "확인"만 보내 줘!

[만드는 페이지]
- 홈 / 회사소개 / 사업분야(분야별 5페이지) / 시공사례 / 한전 신청 안내
- '한전 신청 안내'는 요청서엔 없었는데, 고객들이 많이 찾는 내용이라 넣어 봤어. 첫 화면 볼 때 별로면 뺄게.

[진행 순서]
자료 전달 → 첫 화면 시안 2~3개 중 고르기 → 전체 제작 → 수정(최대 3번, 모아서 한 번에) → 오픈

[오픈 후]
- 새 시공사례는 사진이랑 정보 보내 주면 내가 올려 줄게.

[비용]
- 홈페이지 주소(도메인): 1년에 2만 원 안팎
- 홈페이지 올려 두는 서버: 0원 (무료 서비스 사용)
- 내가 먼저 결제하고, 영수증 모아서 마지막에 한 번에 정산할게.
- 주소랑 계정은 처음부터 회사 이름(볼트온이엔씨)으로 만들어서 나중에 그대로 넘겨줄게.
- 다른 비용이 생길 일이 있으면 결제하기 전에 먼저 물어볼게.
```
