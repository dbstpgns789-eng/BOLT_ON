# 사업분야는 5개: 고압 수변전설비 · 전기 증설·승압 · 변압기 교체 · 내선·리모델링 · 신·증축

업계 9곳 조사(`research/industry/SUMMARY.md`)에서 승압은 증설과 묶고, 리모델링은 내선·인테리어 쪽에 넣는 패턴이 반복되어 그대로 따른다. 다만 업계에서는 변압기를 수변전 분야에 넣는 경우가 많은데도 **변압기 교체를 별도 분야로 둔다**. 클라이언트가 요청서에서 따로 적었고, 고객이 따로 검색하는 단어이기 때문이다. 모자분리·임시전력·한전 신청 대행은 1차 분야가 아니라 관련 분야 페이지의 세부 업무로 넣는다. 분야마다 페이지 주소가 생기므로 나중에 바꾸면 검색 노출이 흔들린다.
