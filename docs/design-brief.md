# 디자인 기준 (시안을 만들 때마다 확인)

## 방문 고객
- 30~60대. 공장·상가·건물 관리자, 건물주.
- 화려하고 예쁜 것보다 **명확하고 깔끔한 것**을 선호한다 (2026-11-10, 사용자 판단).

## 좋은 예 / 나쁜 예 (research/industry/RE-REPORT.md)
| 구분 | 사이트 | 이유 |
|---|---|---|
| 주축 | 우일이엔씨 | 클라이언트 지정 레퍼런스. 구조·정보 표·한전 절차 |
| 좋음 | 신록태양광 | 상단 카테고리 메뉴, 메뉴 아래 사진 슬라이드, 간결한 소개 카드 → 상세 (클라이언트 선택) |
| 좋음 | 하은전기공사 | 깔끔함 |
| 좋음 | 거성전기공사 | 단일 서체, 흰 바탕 + 강조색 하나, 사례 제목에 지역·용량 |
| **금지** | 전기친구들, 연수전기 | 큰 전화번호 배너, 빨간 버튼 줄, 빽빽한 광고 문구, 블로그 광고 같은 느낌 |

## 지켜야 할 것
- 서체: Pretendard(또는 Noto Sans KR). 세리프 한글, 영문 압축 서체는 쓰지 않는다 (시안 A·B가 AI처럼 보인 원인).
- 본문 17px 이상, 보조 글자 15px 이상, 회색 글자는 진하게.
- 강조색(노랑)은 버튼과 작은 표시에만. 면 전체를 칠하지 않는다.
- 팝업, 큰 전화번호 배너, 깜빡이는 효과를 쓰지 않는다.
- 문구는 대표가 쓴 문장을 바탕으로, 문학적인 톤은 살짝만.
