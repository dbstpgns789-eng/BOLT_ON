## 3. 신록 상세 페이지 구조 (`/41`, 클라이언트가 좋다고 한 "누르면 상세")
페이지 배너 + 하위 탭 → "태양광 발전 사업이란?" 짧은 개념 설명 → 슬로건 + 이미지 → 경험·노하우 → **시공 과정 6단계(단계마다 사진)** → 관련 시공사례 카드 3개 → 푸터.
→ 우일이엔씨 사업분야 페이지(용어 각주 + 세부 서비스 + 사진 그리드)와 합치면 볼트온 사업분야 페이지 틀이 된다.

## 4. 볼트온에 주는 의미

| 의견 | 반영 |
|---|---|
| 광고 느낌 싫음 | 큰 전화번호 배너, 빨간 버튼 줄, 팝업, 빽빽한 문구를 쓰지 않는다. 전화 버튼은 메뉴와 하단 고정 바에만 둔다 |
| 상단 카테고리로 스크롤 줄이기 | 메뉴에 마우스를 올리면 하위 항목(사업분야 5개, 시공사례 분야별, 회사소개 하위)이 펼쳐지는 드롭다운. 우일이엔씨 메가메뉴와도 같은 방식 |
| 메뉴 아래 이미지 슬라이드 | 첫 화면을 **꽉 찬 사진 슬라이드(2~3장)**로 바꾼다. 지금 시안 A·B·C에는 없는 형태 → 시안 수정 필요 |
| 간결한 소개 카드 → 상세 | 홈의 사업분야 5개를 사진이 들어간 카드로 만들고, 누르면 분야별 페이지로 이동. 분야별 페이지는 3절 구조 |

## 5. 새로 생긴 과제: 첫 화면 슬라이드용 사진
꽉 찬 슬라이드는 **가로로 긴 고화질 사진**이 필요하다. 지금 받은 사진은 대부분 세로형 카톡 압축본(1058×1411)이다.

| 후보 | 크기 | 판단 |
|---|---|---|
| 김해 복도 라인 조명 (G7·G8) | 4032×2268 가로 | ✅ 바로 사용 가능 |
| 서대문 전시실·조형물 (S5·S6·S7) | 1411×1058 가로 | ⚠️ 1440px 폭에 쓰기에는 해상도가 낮음 → 원본 요청 |
| 하나임푸드 변전설비, 유치원 분전반 | 세로 | ❌ 슬라이드에는 맞지 않음, 카드·사례용 |

대안: 요청서에서 이미 안내한 대로 사용이 허락된 분위기 사진을 쓴다. 단, 실제 현장 사진이 1장 이상은 슬라이드에 들어가야 한다.
