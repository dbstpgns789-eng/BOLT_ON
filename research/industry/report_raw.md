구글과 네이버에서 후보를 찾고, 홈페이지와 하위 페이지를 직접 확인하겠습니다. 화면에서 확인한 사실과 디자인 평가를 구분하고, 확인되지 않은 항목은 그대로 표시하겠습니다.
전기공사 독립 홈페이지 후보를 확보했습니다. 전문 공종형, 지역 출장형, 안전관리 병행형을 나누어 비교하겠습니다. ‘승압’ 등이 메뉴로 독립되어 있는지, 본문에서만 언급되는지도 구분해 확인하겠습니다.
현재 확인한 사이트에서는 같은 공종도 묶는 방식이 다릅니다. 거성전기공사는 변압기 관련 설명을 ‘수배전설비 공사’에 넣고, 우경이엠씨는 모자분리와 수전설비 교체를 ‘전기사고긴급복구공사’에 함께 소개합니다. 나머지 업체도 같은 기준으로 대조하고 있습니다.
일부 사이트는 메뉴와 본문이 이미지로 되어 있거나 스크롤 후 나타나서, 텍스트 목록만으로는 빠지는 내용이 있습니다. 화면과 본문을 함께 확인 중입니다. 제작 방식은 근거가 있는 경우만 적고, 정적 페이지라는 이유로 ‘자체 제작’이라고 단정하지 않겠습니다.
중부전기는 자체 면허업체가 아니라 다른 면허 법인의 마케팅·접수처라고 명시하고 있어, 일반 시공업체와 구분해 별도 참고로 정리하겠습니다. 또 현장명·완료일·용량이 있는 실적과 지역별 정보성 글을 나누어, 글 수를 공사 실적 수로 잘못 세지 않겠습니다.
8개 업체의 핵심 항목 확인을 마쳤습니다. 다만 ‘대표 사례 3개 노출’과 ‘전체 사례가 3개뿐인 사이트’는 다릅니다. 사례가 적은 화면 구성은 이 차이를 명시해 정리하고, 가능하면 전체 공개 사례가 2~5건인 업체도 추가로 확인하겠습니다.
정리해 보니 메인에서 시공사례를 바로 보여 주는 업체도 있지만, 사업·신뢰 정보를 먼저 보여 주거나 사례 메뉴만 두는 업체도 있습니다. 공통 패턴은 8개 업체 안에서 확인된 범위로만 집계하겠습니다. 우일이엔씨의 기존 분석 원문은 없어 ‘우일에는 없다’는 단정은 피하고, 차별화 검토 후보로 표시하겠습니다.
추가로 신록태양광에너지의 ‘전기공사’ 게시판에서 공개 사례 4건을 확인했습니다. 태양광 사례는 별도로 많으므로 전체 실적이 적은 회사라고 볼 수는 없지만, 전기공사 4건을 보여 주는 화면의 참고로 포함하겠습니다. 최종 결과는 일반 전기공사 중심 8곳과 태양광 병행 보조 1곳으로 정리합니다.

아래는 **헤더·푸터를 제외하고 히어로를 1번째로 센 기준**입니다. 서비스 카드 여러 개는 하나의 사업 소개 섹션으로 묶었습니다.

| 업체 | 핵심 순서 | 시공사례 위치 |
|---|---|---|
| 하은 | 히어로 → 회사소개 → 사업 → 사례 → 견적 → 콘텐츠 | **4번째** |
| 에디슨 | 히어로 → 지표·회사 → 솔루션 → 사업 → 인증·파트너 → 콘텐츠 → 견적 | 독립 사례 목록 섹션 미확인 |
| 한결 | 히어로 → 회사·사업 진입 카드 | 메인 사례 없음 |
| 연수 | 히어로 → 신뢰 띠 → 서비스 → 선택 이유·절차 → 사례 → 가이드·지역 → 견적 | **5번째** |
| 명군 | 히어로 → 문제별 서비스 → 출장·범위·지역 → 블로그 → 상담 | 실제 사례 대신 정보성 블로그 |
| 전기친구들 | 히어로 → 서비스 → 상담 배너 → 사례 블로그 → 문의 현황 | **4번째** |
| 거성 | 히어로 → 사례 → 사업 → 문의 | **2번째** |
| 우경 | 이미지형 안내 → 인력 → 소개 → 사업 → 본지사 | 메인 사례 목록 미확인 |
| 신록 | 히어로 → 상품 → 사례 → 회사 영상 → 문의 | **3번째** |

### 요약

- **완전히 동일한 최빈 순서는 없었습니다.**
- 반복되는 큰 골격은 **히어로 → 사업·신뢰 정보 → 사례 또는 콘텐츠 → 문의**입니다.
- 사례가 있는 5곳의 위치는 **2·3·4·4·5번째**입니다. 가장 자주 나온 위치는 4번째지만, **5곳 중 2곳**이므로 강한 업계 표준으로 볼 수는 없습니다.
- 거성처럼 **사례를 바로 2번째에 놓는 방식**도 분명히 존재합니다.

| **사례 데이터 표준화** | 에디슨: 지역·완공일·기간·수전용량·변압기·케이블 | 사례마다 지역 / 공종 / 용량 / 기간 / 작업범위 5개 필드 고정 |
| **문제 → 작업 → 확인사항** | 연수 내부 사례 상세 | 공사 전 고객 문제와 실제 해결 내용을 짧게 연결 |
| **지역·용량을 사례 제목에 노출** | 거성: ‘화성…600kW H주 수변전’ | 썸네일만 보더라도 어떤 규모의 공사를 했는지 전달 |
| **분야별 대표 실적 표** | 한결: 현장명·발주처·기간 표 | 사진 공개가 어려운 현장은 익명화 실적 표로 보완 |

# D. 사례가 2~5건일 때 참고할 실제 화면

**전체 시공 실적이 2~5건뿐인 소규모 회사라고 확정한 업체는 없습니다.** 대신 ‘공개한 특정 분야가 4건’, ‘메인 대표 사례가 3건’인 화면은 확인했습니다.

| 실제 관찰 | 사례 수의 정확한 의미 | 화면을 구성하는 방식 |
|---|---|---|
| **신록 전기공사 게시판 4건** | 전기공사 카테고리 공개 4건. 회사 전체 사례는 더 많음 | 카테고리를 분리하고, 한 사례 상세에 여러 현장 사진 제공. 직접 확인 상세는 사진 7장 |
| **한결 전기공사 대표 현장 4개 행** | 총실적 표기는 9건이며 공개 대표 행이 4개 | 사진 카드 대신 **현장명·발주처·기간 표**, 분야별 실적 수치와 인허가로 보완 |
| **연수 메인 대표 사례 3개** | 전체 사례는 9건 | 대표 카드 앞 현장 사진 갤러리, 뒤 문제 해결 가이드·지역·문의 섹션 배치 |
| **명군의 현장 포트폴리오 미확인** | 실제 실적이 적다는 뜻은 아님 | 문제별 서비스·출장 안내·지역·블로그·Wiki로 메인 구성. 다만 현장 실적의 증명은 약함 |

### 볼트온에 적용할 때의 의견

사례가 2~5건이면 빈 카드나 같은 사례를 반복하기보다 다음 구성이 적절합니다.

1. **대표 사례 2~3건을 크게 노출**
2. 각 상세에 **공사 전 / 작업 중 / 완료 후 사진과 설명**
3. **주력 공종 5개**를 분명하게 설명
4. **상담 → 현장 확인 → 견적 → 한전·검사 절차 → 시공·인계** 안내
5. 실제 보유한 **면허·자격·장비·담당자 정보**로 보완

이는 조사에서 확인한 구성 요소를 조합한 **제안**이며, 실적 수를 부풀리거나 정보성 글을 시공사례로 세는 방식은 권하지 않습니다.
