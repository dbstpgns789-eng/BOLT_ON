# 사업분야 페이지 분석 (2026-11-10)

홈의 사업분야 카드 6개(5개 분야 + 한전 신청 대행)를 누르면 오는 페이지다. 캡처 원본은 `research/_raw/`(git 제외).

## 1. 이 페이지의 목적
홈 카드를 누른 고객은 이미 "이 공사가 필요한가?"를 생각하고 있다. 30~60대 건물 관리자·건물주가 이 페이지에서 답을 얻어야 할 질문은 다섯 가지다.

1. **내 상황에 이 공사가 맞나?** (차단기가 자주 떨어진다, 장비를 늘린다, 변압기가 오래됐다)
2. **무엇까지 해 주나?** (작업 범위, 한전 서류 포함 여부)
3. **어떻게, 얼마나 걸려 진행되나?** (단계, 기간)
4. **나는 무엇을 해야 하나?** (고객이 직접 내는 시설부담금 등)
5. **실제로 해 본 회사인가?** (같은 분야 시공사례)

그리고 답을 얻은 뒤 바로 **전화**로 이어져야 한다.

## 3. 볼트온이 가진 소재

| 분야 | 설명·작업(`services.ts`) | 시공사례 | 공정 사진 |
|---|---|---|---|
| 고압 수변전설비 | ○ | 청주 식품공장 변전실 | ○ 기초 → 설치 → 결선 |
| 전기 증설·승압 | ○ | 동대문 유치원 (공사 전·후) | 분전반 전·후 |
| 변압기 교체 | ○ | **없음** | **없음** |
| 내선·리모델링 | ○ | 서대문형무소, 김해 미술관 | ○ |
| 신·증축 | ○ | **없음** (김해 미술관을 넣을지 확인) | |

**모르는 것 (클라이언트 확인)**: 분야별 실제 소요 기간, 단계별 담당(특히 시설부담금은 고객 납부인지), 자주 받는 질문. 공사 이력 엑셀에 "시설부담금 고객 납부"가 여러 번 나오지만 엑셀은 사용 보류 상태이므로, 사실 확인 없이 숫자나 기간을 쓰지 않는다.

## 4. 볼트온 사업분야 페이지 구조 (제안)
1. 페이지 배너(짧게) + 분야 탭 5개 — 우일·신록
2. 분야 소개 + 용어 상자 1개 ("계약전력이란?") — 우일·신록
3. **이런 경우 필요합니다** (상황 3~4개, 고객의 말로) — 에디슨·우일
4. **작업 범위** (볼트온이 하는 일 목록) — 에디슨·거성
5. **진행 절차와 담당** (볼트온 / 고객 / 한전·안전공사 표시, 기간은 확인 전까지 비움) — 에디슨 + 우일 화살표
6. **이 분야 시공사례** — 신록 (사례가 없는 분야는 이 블록을 숨김)
7. **자주 묻는 질문 3개** — 에디슨 (초안 작성 → 클라이언트 확인)
8. 상담 띠 (전화 하나, 광고처럼 크지 않게) — 거성
9. 다른 분야 바로가기 — 에디슨

## 5. 시안 계획
소재가 가장 많은 **전기 증설·승압**으로 3안을 먼저 만든다.
- **S1 우일형**: 배너 + 탭 + 세부 업무 아이콘 + 화살표 절차 + 사진 격자
- **S2 에디슨형**: 단계 목록에 담당 표시 + 작업 범위 + 자주 묻는 질문 (정보가 가장 많음)
- **S3 신록형**: 개념 설명 + 사진이 붙은 절차 + 사례 카드 (가장 간결함)
