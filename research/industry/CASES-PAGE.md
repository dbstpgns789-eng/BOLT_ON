# 시공사례 페이지 분석 (2026-11-11)

캡처 원본: `research/_raw/` (우일 case, 에디슨 cases·case-detail, 거성 works·work-detail, 신록 cases, 한결 performance, 하은 case-detail).

## 1. 목적
홈 "전체 보기", 사업분야 페이지의 "이 분야 시공사례"에서 들어온다. 고객이 확인하려는 것은 하나다: **나와 비슷한 현장을 실제로 해 봤는가.** 그래서 목록은 "어떤 건물·어떤 공사"를 빨리 훑게 하고, 상세는 "무엇을 어떻게 했는지"를 사진과 사실로 보여 준다.

## 3. 볼트온 소재
사례 4건(`src/content/cases`): 제목, 현장명(실명/익명), 지역, 건물, 분야, 완공 연월, 기간, 작업 태그, 단계별 사진(공사 전·중·후).
- 공사 전·후 짝이 있는 사례: 동대문 유치원(분전반 2쌍).
- 공정 순서가 있는 사례: 청주 변전실(기초 → 설치 → 결선).
- **없는 것**: 용량(kW·kVA), 상세 설명 글. → 사실만으로 짧은 요약을 쓰고(클라이언트 확인), 용량은 받으면 표에 추가.
- 사진 없는 공사 이력 표(한결형): 엑셀 정리본을 받으면 추가.

## 4. 시안
목록 + 상세를 한 세트로 3안. 모두 같은 데이터, 블록 구성만 다르다.
- **C1 우일·거성형**: 분야 필터 + 3열 사진 카드 / 상세는 공사 개요 문단 + 작업 목록 + 사진 묶음 + 목록으로.
- **C2 에디슨형**: 필터 + 정보가 많은 카드(지역·완공·기간·태그) / 상세는 공사 전·후 드래그 비교 + 공사 정보 표 + 번호 작업 목록.
- **C3 하은·신록형**: 사진 왼쪽·글 오른쪽 가로 목록 / 상세는 큰 대표 사진 + 요약 + 단계별 사진(공사 전·중·후) + 이전·다음 사례.
