## 2. 페이지별 섹션 순서

### 메인
1. **헤더**: 로고(원형 심볼 + 국문 상호 + 영문 상호) · GNB 5개 · 검색 / 사이트맵 / 블로그 아이콘. 어두운 히어로 위에 투명하게 겹친다.
2. **히어로**: 어두운 남색 질감 배경 + 오른쪽 사진(송전탑), 왼쪽에 "01 / 03" 슬라이드 번호 · 대형 영문 헤드라인 · 국문 한 줄 · 외곽선 버튼. 아래 중앙에 주황 스크롤 버튼.
3. **사업분야 슬라이더**: 상단 오른쪽에 분야 탭 4개, 왼쪽에 남색 패널("Business 01" 주황 라벨 → 큰 국문 제목 → 설명 → View More), 오른쪽에 사진이 패널과 겹쳐 놓인다.
4. **시공사례 캐러셀**: 가운데 정렬 영문 제목(2색) + 국문 부제 → 카드 3장(사진, 한 줄 제목 말줄임, 날짜, 하단 선) → View More.
5. **고압 수변전설비 시공사례 캐러셀**: 4와 같은 구조.
6. **문의 띠**: 어두운 사진 배경, 왼쪽 "무엇이든 물어보세요!", 오른쪽 아이콘 타일 3개(FAQ, A/S, 견적).
7. **공지사항**: 회색 배경, 왼쪽 제목 + 바로가기, 오른쪽 흰 카드 2장 캐러셀.
8. **배너 2개**: 따뜻한 나눔(스톡 사진) · 한전서류 신청 절차(일러스트).
9. **푸터**: 어두운 배경 3단(회사 정보 / Contact Us / 메뉴 링크).
10. **하단 고정 상담 바**: 전화(대표번호 주황 강조) · 카카오톡 · 견적상담 · 신청절차 · TOP.

### 서브 페이지 공통 틀
페이지 배너(배경 사진 + 국문 제목 + 영문 부제 + 브레드크럼) → 2차 메뉴 탭(모바일은 셀렉트 2개) → 가운데 정렬 페이지 제목 → 본문 → 푸터.

## 5. 인터랙션
- 헤더: 아래로 스크롤하면 숨고, 위로 스크롤하면 고정 상태로 다시 나타난다. GNB 호버 시 전체 드롭다운.
- 사업분야: slick 페이드 슬라이더, 5초 자동 전환, 탭 = 점 내비게이션.
- 시공사례: 3장(681px 미만 2장) 캐러셀, 4초 자동 전환. 공지: 2장 캐러셀.
- 하단 상담 바: 항상 고정, 접기 버튼. TOP 버튼은 이징 스크롤.
- 기술: jQuery 1.12, jQuery UI, slick, TweenMax(GSAP 2), PageScroll2id. 2016년 전후 방식.

## 6. 콘텐츠 패턴 (가장 가치 있는 부분)
- **사례 제목 공식**: "지역(시·구·동) + 건물 유형 + 전기공사 (공사 내용 + 용량 시공 사례)"
  - 예: "서울 영등포 당산 상가 전기공사 (단상 5KW → 3상 10KW 전기 증설/승압 시공 사례)"
  - 지역 검색어("○○동 전기공사")를 노린 구조이고, 볼트온 사례 정보 요청(P1-7)의 근거가 된다.
- **용어 각주**: "*계약전력이란?", "*수변전설비란?"처럼 비전문가 고객을 위한 짧은 설명을 붙인다.
- **세부 서비스 아이콘**: 증설·승압·신설·모자분리·구좌분할·임시전력처럼 고객이 실제로 검색하는 단어로 나눈다.
- **한전서류 절차 페이지**: 면허업체만 한전 신청이 가능하다는 점, 소요 기간(3~7일), 준비 서류를 정리한다. 볼트온 소개문의 "한전 신청 서류도 함께 준비"와 정확히 맞물린다.
- **회사개요 표**: 설립일 · 사업자번호 · **전기공사업 면허번호** · 보유면허를 표로 공개한다 → 볼트온 P0-1, P0-2 요청의 근거.

## 7. 유입 구조
- 네이버 서치어드바이저 인증 메타 있음, meta keywords에 지역·공사 키워드 나열.
- 시공사례 상세는 전부 네이버 블로그 글로 연결 → 블로그 검색 유입을 노린 방식이지만, 사이트 체류는 끊긴다.
- 대표번호 1588 + 휴대폰 + 카카오 오픈채팅 + 견적 폼으로 문의 경로가 4개다.
- 외부 추적 스크립트(toup.net 로그), 구버전 GA(analytics.js, 이미 수집 중단된 방식).

## 8. 약점
1. 히어로 슬라이드 3장이 모두 같은 내용이다.
2. 영문 헤드라인("HIGHTECH ELECTRICAL SERVICES")이 일반적이라 회사를 설명하지 못한다.
3. 공지사항이 2021년에 멈춰 있어 방치된 인상을 준다.
4. "따뜻한 나눔"에 업무와 무관한 스톡 사진(아이들)을 쓴다.
5. 하단 고정 바가 본문을 가리고, 모바일에서 화면을 많이 차지한다.
6. 사례 제목이 길어 카드에서 잘리고, 썸네일 화질이 낮다. 같은 사례가 중복 노출된다.
7. 사례 상세가 외부 블로그로 빠져나간다.
8. 메인 첫 화면이 어둡고 사진이 많다 → 볼트온 클라이언트가 피하고 싶은 것("너무 화려함", "사진이 너무 많음")과 반대 방향이다.
9. 오래된 기술 스택과 추적 스크립트 때문에 무겁다.

### 볼트온 사이트맵 초안 (ADR 0006에서 확정)
```
홈
회사소개        회사 개요(정보 표·면허) · 강점 · 오시는 길(지도 링크)
사업분야        고압 수변전설비 · 증설 · 변압기 · 내선 · 신축  (+승압/리모델링은 P1-8)
시공사례        목록(분야 필터) → 사례 상세
한전 신청 안내  절차 · 준비 서류 · 소요 기간   ← 추가 후보 (Phase 2에서 결정)
(공통) 하단 상담 버튼 · 푸터(상호·대표·사업자번호·면허번호·주소·연락처)
```
요청서 메뉴 3개를 기본으로 하고, 한전 신청 안내 1개를 추가할지를 그릴링에서 결정한다.
